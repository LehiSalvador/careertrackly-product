# Careertrackly: contexto y alcance

Careertrackly busca conectar información profesional dispersa entre CV, LinkedIn, GitHub, certificaciones y proyectos. Su propuesta es construir una identidad profesional sustentada en evidencia y convertirla en un portafolio que pueda publicarse y explorarse.

## Estado documentado

Arquitectura conceptual V1 · desarrollo funcional inicial. La arquitectura conceptual V1 está ampliamente definida. El desarrollo funcional permanece en una etapa inicial. Las capacidades descritas corresponden al alcance de producto definido; este repositorio documenta esa visión y estructura.

Lehi Salvador — definición de producto y arquitectura conceptual V1 dentro del ecosistema Salva Systems.

Esta documentación amplía la información proporcionada por el responsable del producto. Los criterios y siguientes pasos de la hoja de ruta son propuestas de documentación pública; no compromisos de entrega ni capacidades adicionales implementadas.

## Flujo de referencia

1. Professional Profile.
2. Projects + Evidence.
3. Portfolio.
4. Publish.
5. Explore.

El flujo describe el contexto del producto. No define una API, integración ni procedimiento productivo listo para ejecutar.

## Vocabulario

| Concepto | Significado en este contexto |
| --- | --- |
| Perfil profesional | Identidad que conecta trayectoria, proyectos y habilidades. |
| Proyecto | Trabajo que aporta contexto a una experiencia profesional. |
| Evidencia | Referencia que respalda una afirmación; su existencia no prueba por sí sola calidad o autoría. |
| Habilidad | Capacidad asociada con trabajo y evidencia. |
| Portafolio | Selección de información preparada para compartir. |
| Publicación | Exposición deliberada de una versión del portafolio mediante URL. |

## Límites de publicación

- Arquitectura conceptual V1 ampliamente definida; desarrollo funcional inicial.
- Editor no-code, asistencia de IA, SEO y analytics pertenecen al alcance conceptual; este repositorio no acredita su implementación.
- Los datos privados del perfil no deben convertirse automáticamente en evidencia pública.

Los sistemas reales y su infraestructura se administran por separado. Este repositorio no contiene instrucciones para acceder a clientes o desplegar aplicaciones.
